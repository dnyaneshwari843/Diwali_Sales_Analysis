# Diwali Sales Analysis

*Objective:
To analyze Diwali sales data to understand customer behavior during festival season.

*Steps Done:
1. Data Cleaning - Removed null values and unused columns
2. Gender Analysis - Female customers are 3x more than Male
3. Age Analysis - 26-35 years age group is top buyer and highest spender
4. State Analysis - UP, Maharashtra, Karnataka are top 3 states in orders and amount

* Graphs Generated:
1. Gender Count
2. Purchase based on Gender  
3. Sales based on Age Group
4. Total Amount vs Age Group
5. Top 10 States by Orders
6. Top 10 States by Amount

# Tools Used:
Python, Pandas, NumPy, Matplotlib, Seaborn
